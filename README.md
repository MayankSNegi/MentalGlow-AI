## 🧠 Overview

**MentalGlow-AI** is an intelligent mental wellness web platform designed to help users self-assess their **emotional and psychological well-being**.  
It leverages **Machine Learning (Random Forest Classifier)** and **FastAPI** to predict mental wellness risk levels based on behavioral, emotional, and lifestyle patterns.

---

## 🌟 Key Features

- 🧩 **AI-Powered Predictions** – Predicts user’s mental health risk (Low / High).  
- 💬 **Real-Time Insights** – FastAPI backend delivers predictions instantly.  
- 🎨 **Modern UI** – React-based responsive frontend design.  
- 🧮 **Data-Driven** – Built from curated and cleaned wellness datasets.  
- 🔐 **Privacy-Focused** – Designed for ethical and private assessment.
